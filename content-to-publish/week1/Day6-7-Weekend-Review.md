## 📋 TASK 3: Schema Validation (10 minutes)

### How to Validate

Use **Google Rich Results Test** (`https://search.google.com/test/rich-results`):

1. Go to the URL above
2. For each page, paste the URL:
   - Burlington URL
   - Oakville URL
   - Milton URL
3. Click **"Test URL"**
4. Review results:
   - ✅ Green = Schema is valid
   - ⚠️ Yellow = Warnings (usually non-critical)
   - 🚨 Red = Errors (must fix)

### What to Look For

**Valid Schema Types Expected:**
- ✅ LocalBusiness
- ✅ FAQPage
- ✅ BreadcrumbList

**Common Issues to Watch For:**
- Missing required fields
- Invalid JSON syntax
- Schema type mismatch

### If Errors Found
- Document the error
- Note which schema type has the issue
- Plan fix for Monday (Day 8 / Week 2 start)
