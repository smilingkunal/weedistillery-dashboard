# 🎯 CRITICAL SUCCESS FACTORS

## Must Do
1. ✅ Publish consistently every week (no gaps)
2. ✅ Maintain quality (don't sacrifice for speed)
3. ✅ Add real images to every page
4. ✅ Monitor rankings weekly
5. ✅ Build backlinks continuously

## Must Avoid
1. ❌ Auto-generated thin content
2. ❌ Publishing without QA score ≥85
3. ❌ Ignoring technical errors
4. ❌ Stopping after 90 days (this is a 12-month commitment minimum)

## Red Flags to Watch For
- Pages not indexing after 2 weeks → check robots.txt, canonicals
- Sudden traffic drop → check for penalties
- Schema errors → run Rich Results Test
- Quality score <85 → regenerate before publishing
